# MeetingLens 开发预览使用手册

> 开发预览版：本手册描述当前仓库实际可用的本地桌面流程。它不是正式产品手册，也不表示真实转录或 AI 纪要已经可用。

## 1. MeetingLens 简介

MeetingLens 是面向 Windows 11 的本地优先会议工作台。产品目标是把粘贴或导入的会议转录转化为详实、可编辑、可追溯的会议纪要；当前开发预览版主要用于验证会议管理、安全文件导入、本地服务和安全设置边界。

同一个应用内置简体中文（`zh-CN`）和 English（`en-US`），不需要安装两个版本。

## 2. 当前版本状态

当前版本是开发预览版。现有能力包括：

- 创建、编辑、开始、结束和删除本地会议；
- 运行纯合成、仅内存中的模拟字幕流程；
- 通过系统文件选择器安全导入、去重、列出和删除会议文件副本；
- 查看 Mock Provider、本地 Sidecar 和数据库状态；
- 将 DeepSeek API Key 保存到 Windows Credential Manager，且 WebView 无法读回；
- 运行独立离线 Docling Worker 的开发验证，但该 Worker 尚未接入产品界面。

当前不能生成真实会议纪要，也不能处理真实录音或实时转录。

## 3. 系统要求

- Windows 11；
- WebView2；
- 从源码运行时需要 Node.js 22+、npm 10+、Python 3.12.x、Rust stable 和 Visual Studio Build Tools 2022；
- Build Tools 需要 Desktop development with C++、MSVC v143、Windows 10/11 SDK 和 C++ CMake tools。

Windows 11 与 Python 3.12 是项目基线，其他系统或 Python 版本不能替代正式验收。

## 4. 启动应用

从仓库根目录安装锁定依赖并启动桌面开发版：

```powershell
npm ci
npm run tauri dev
```

完整自动检查使用：

```powershell
npm run check
```

看到原生 MeetingLens 窗口并确认设置页显示本地运行状态后，才算桌面应用实际启动。CI 通过不能替代本机窗口验收。

## 5. 首页介绍

首页显示会议状态摘要、最近会议和“新建会议”入口。当前摘要中的“待准备”“会议进行中”和“可继续处理”对应内部稳定状态，但页面不会要求用户直接操作内部状态值。

首页目前没有粘贴转录、导入转录或生成纪要快捷入口；这些入口属于后续 transcript-first 阶段。

## 6. 创建会议

1. 选择左侧“新建会议”。
2. 输入便于识别的简短标题。
3. 选择“创建会议”。
4. 在会议详情页确认标题、时间线、语言基线和文件区域。

创建会议只保存本地元数据，不会申请麦克风、屏幕、网络模型或文件访问权限。

## 7. 模拟会议流程

1. 在草稿会议详情页选择“开始会议”。
2. 应用进入模拟会议界面，并显示合成字幕。
3. 可以暂停或继续模拟字幕，并添加仅保存在内存中的重点标记。
4. 选择“结束会议”。
5. 应用回到会议详情，会议显示为“可继续处理”。

模拟字幕不是录音、实时 ASR 或真实会议内容。关闭页面后，临时字幕、笔记和重点标记不会作为真实转录保存。

## 8. 导入和管理会议文件

1. 打开会议详情页，选择“添加文件”。
2. 使用 MeetingLens 打开的系统文件选择器选择允许的文件。
3. 查看验证、复制、保存、重复或失败进度。
4. 导入成功后，在会议文件列表查看安全显示名、类型、大小、时间和状态。

源绝对路径不会返回 WebView。MeetingLens 将允许的文件复制到应用私有存储；源文件不被修改。文件当前不会在界面中打开或解析，也不会发送给 Sidecar、Docling 或 DeepSeek。

## 9. 设置 DeepSeek API Key

1. 打开“设置”。
2. 在 DeepSeek API 区域输入 Key。
3. 选择“保存 API Key”。
4. 确认状态显示“已配置”，输入框保持为空。

Key 保存在当前 Windows 用户的 Credential Manager 中，而不是 SQLite、WebView 存储或仓库。界面只能查询配置状态、写入和删除，不能读回 Key。当前没有真实 DeepSeek Provider 使用它。

不要把 Key 粘贴到问题报告、日志、截图、会议记录或版本控制中。已暴露的 Key 应立即撤销。

## 10. 切换界面语言

1. 打开“设置”。
2. 找到“界面语言”。
3. 选择“简体中文”或“English”。
4. 页面文案会立即切换。

应用只在非敏感 WebView 偏好 `meetinglens.uiLocale` 中保存允许的 locale 枚举。重启后会保留用户选择；清除 WebView 存储只重置界面语言，不会删除会议、文件副本或凭据。

界面语言与未来会议纪要输出语言相互独立。当前版本没有纪要输出语言设置。

## 11. 查看历史会议

选择左侧“历史记录”，可以查看按创建时间排序的会议。每项显示本地化状态和创建、开始、结束时间。选择“查看详情”可返回会议详情和文件列表。

关闭并重新打开应用后，SQLite 中的会议记录仍应存在。模拟字幕和临时笔记不属于持久化会议转录。

## 12. 删除会议和文档

文档删除：

1. 在会议详情中选择某个文档的“删除”。
2. 确认只删除 MeetingLens 本地副本；源文件保持不变。
3. 删除失败时使用“重试删除”。

会议删除：

1. 只有“待准备”或“可继续处理”的会议可以请求删除。
2. 会议进行中必须先结束。
3. 确认删除后，MeetingLens 会协调数据库记录与受控文件副本。
4. “正在删除”或“需要处理”表示恢复流程尚未完成，不应重复创建替代数据。

删除是不可撤销操作。执行前确认选中的会议和文件正确。

## 13. 数据存储和隐私

- 会议元数据保存在应用私有 SQLite 数据库中；
- 导入文件副本位于应用私有存储，React 不取得绝对路径；
- DeepSeek Key 位于 Windows Credential Manager；
- 界面语言是唯一允许写入 WebView 偏好存储的应用设置；
- 当前预览版不会录音、读取屏幕或向外部 AI 发送会议内容；
- 测试和问题报告只能使用合成数据。

详细边界见 [SECURITY.md](../SECURITY.md)。

## 15. 常见问题

### 为什么已经保存 DeepSeek Key，却不能生成纪要？

当前只完成安全凭据存储。真实 Summary Provider、输入快照、发送预览和证据验证将在后续独立阶段实现。

### 导入文件后为什么没有解析结果？

当前 UI 只完成安全复制和生命周期管理。离线 Docling Worker 已完成开发基础，但尚未连接数据库、命令或界面。

### 切换语言会翻译会议标题或文件名吗？

不会。标题、文件名和未来转录均是用户数据，不会被当作翻译 key 或自动翻译。

### 清除浏览器或 WebView 存储会删除会议吗？

不会，只会重置非敏感界面语言偏好。会议和文件由本地数据库与私有文件存储管理。

## 16. 故障排查

- 应用无法启动：确认 C++ Build Tools、WebView2、Rust、Node.js 和 Python 3.12 可用，再运行 `npm run check`。
- 本地服务不可用：关闭残留开发进程后重新启动应用；不要自行降低认证或安全检查。
- 数据库不可用：停止写入操作并保留错误代码，不要直接修改或删除数据库文件。
- 文件导入失败：检查格式、大小、配额和文件完整性；不要通过改扩展名绕过校验。
- 安全存储不可用：确认在受支持的 Windows 用户会话中运行；不要改用明文文件。
- 报告问题时提供操作步骤、应用版本和稳定错误代码，不要附上 Key、会议内容、录音、数据库、日志、私有路径或上传文件。

## 17. 后续计划

下一条核心交付路径是：

1. `feat/transcript-data-core`：schema v3、转录来源和片段、粘贴/TXT/SRT/VTT 本地解析；
2. `feat/transcript-import-ui`：粘贴、原生导入、预览和首页入口；
3. `feat/deepseek-summary-mvp`：transcript-only 纪要、不可变快照、模板、证据和 Markdown；
4. `feat/summary-editing-export`：编辑、revision、stale、章节重生成和 DOCX；
5. `feat/document-parsing-orchestration` 与 `feat/document-evidence-index`：后续参考文档增强。

完成前三项后，MeetingLens 才达到从已有转录生成真实会议纪要的最低日常使用门槛。未来阶段和分支以 [DEVELOPMENT_PLAN.md](../DEVELOPMENT_PLAN.md) 为准，PR 编号只记录实际创建后的历史。
